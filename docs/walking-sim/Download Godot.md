# Download Godot

## Download

First things first, we’re going to download Godot.
Go to the official website [godotengine.org](https://godotengine.org/download) and hit the download button that matches your operating system, and you’re done!

In this tutorial, I’m using Windows OS. I hope it won’t feel complicated if you’re on another system.
If you find it tricky to set up Godot on your OS, try a quick YouTube search for installation guides - it’s usually very simple.

:::info Instantly Beautiful 🔥
Godot is one of the most lightweight mainstream game engines. 
It’s fast to download, easy to set up, and doesn’t require installation.
:::

:::info Safe to Run 🚀
If Windows Defender shows a warning, click **More info** → **Run anyway**  
 *(download from the official website)*.
:::

## Make It Easy to Access

Godot is not like other software. You don’t need to install it to use it. Just double click the file and you’re already in the editor. You can keep this file anywhere you like and open it whenever you need Godot.

If you prefer to make it feel more like a normal program, you can:

* Go to your **Program Files** folder
* Create a folder named **Godot**
* Move the file inside it
* Right click the file and choose **Send to → Desktop (create shortcut)**

Now you can access it easily from your desktop.
You can also right click and **Pin to Start** or **Pin to Taskbar** if you want quick access.

![Placing it somewhere easy to access](img/Download%20Godot/pin.png)

You don’t have to do all of these steps. Just keep it somewhere easy to find.
I recommend keeping it in a visible place so you can jump into Godot anytime.

:::info Make it a habit 💪
Placing it somewhere easy to access will save you a few seconds each time. And remember, just opening the editor and experimenting regularly helps you learn faster. Believe me, this small step makes a big difference.
:::
