# Project Settings and Export

## Project Settings

Let's talk about **project settings**.  
Go to Project → Project Settings  
![export](<img/Project Settings and Export/export (1).png>)

In the **General** tab, under **Configs**, you can change the project name, description, icons, and more.  
![export](<img/Project Settings and Export/export (2).png>)

Under **Display → Window**, you can change the screen size, mode, and other display options.  
![export](<img/Project Settings and Export/export (3).png>)

Change the mode to **Fullscreen** so it looks better after export, then close the window.  
![export](<img/Project Settings and Export/export (4).png>)

## Export

Now it’s time to export your game.  
But when you export for the first time, you need an additional component called **Export Templates**.  

So first, we need to download those templates.

Go to **Editor → Manage Export Templates**.  
![export](<img/Project Settings and Export/e10.png>)

You will see a message saying:  
 **“Export templates are missing. Download them or install from a file.”**  
![export](<img/Project Settings and Export/e11.png>)  
Click **Download and Install**. This is the easiest option because it automatically downloads the correct version.

You will need an active internet connection for this. Also, the templates are nearly **1 GB in size**, so it may take some time to download.
After the installation is finished, you can close the window.

:::info One Time Setup ✋
You only need to do this one time. You don’t need to repeat it for every project.
:::

Now we are ready to export our project.

Go to Project → Export  
![export](<img/Project Settings and Export/export (5).png>)

First, add an **Export Preset**. I chose **Windows Desktop**.  
![export](<img/Project Settings and Export/export (6).png>)

Tick **Embed PCK** and then **Export Project**.  
![export](<img/Project Settings and Export/export (7).png>)

It will ask where to save. I made a **builds** folder and kept the name the same.  
Remove the tick from **Export with Debug**, then click **Save**.  
![export](<img/Project Settings and Export/export (8).png>)

Now you have your game as an **.exe file**.  
Give it to your friends to try. That’s it for this tutorial...  
![export](<img/Project Settings and Export/export (9).png>)
